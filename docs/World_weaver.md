## THE WORLD WEAVER  

### The heart and engine  
This is the heart and engine of the operation, where the action happens, were you make your changes.  

### How to use  
* If you just added a character to the database, Restart ComfyUI and refrshe the node definitions to see it in the list
* Enter the clothing, hairstyle and accessories in the Chcrcter Select node, or leave empty for default
* Enter the [camera shot type](https://zanno.se/learn-to-control-the-perspective/), the action (verb), and the where in the corresponding nodes
* List any loras you might want to use in the Conditional LoRa Applier, your negative prompt
* Add triggerwords you want to use in the Concatenate node
* Make sure you have your API key, and that you have placed the path to it in the Gemini API node
* Execute the workflow
