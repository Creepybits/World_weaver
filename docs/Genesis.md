## THE GENESIS

### Optional  
This step is also optional, and is meant to show you the visual representation of your prompt before you decide to save the character data.  

### How to use  
* Copy the prompt from the [Prompt Helper](./docs/Prompt_Helper.md)
* Paste the prompt in the Master Key node
* Decide if you want to use any LoRa, and list them in the Conditional Lora Applier node
* Set negative prompt in the negative prompt node, and any trigger words you might want in the Concatenate node
* Execute the workflow
