## THE CHARACTER VAULT (DATABASE)  

### The storage  
Here's where you name and store the character you have created.  

### How to use  
* Copy the prompt from the [Prompt Helper](./docs/Prompt_Helper.md) or the [Genesis](./docs/Genesis.ms)
* Paste it in the Character Vault node
* Important! - Clean up the prompt some and add {placeholders} (see image below)
* Name your character and set "Save to db" as true
* Execute the workflow

### The Character Vault  
Tips: add *dressed in {clothing}* to make sure you easily can change the outfit later on, only keep the feature regarding the hair that you wont change (as color and length) and add {hairstyle} as placeholder, remove any accessories you don't want to be permanent in every image and add {accessories} as placeholder.
