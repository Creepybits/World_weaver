## THE WORLD WEAVER PROMPT HELPER  

### The optional step  
The prompt helper is competely optional, and is meant to help you structure the prompt for a character to save to your database.  

### How to use
* Load an image
* Make sure you have obtained an [API key from Google](https://aistudio.google.com/api-keys)
* Execute the workflow
* Review the output prompt
